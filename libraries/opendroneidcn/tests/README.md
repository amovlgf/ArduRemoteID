# Host verification

Build from the repository root:

```sh
cmake -S libraries/opendroneidcn -B /tmp/arduremoteid-cn-codec-build -DCN46750_SANITIZE=ON
cmake --build /tmp/arduremoteid-cn-codec-build
cd /tmp/arduremoteid-cn-codec-build
ctest --output-on-failure
```

On a host running the process under ptrace, LeakSanitizer cannot inspect threads.
Use `ASAN_OPTIONS=detect_leaks=0 ctest --output-on-failure` there; address,
undefined-behavior and floating-to-integer overflow checks remain enabled. The
codec does not allocate heap memory. A normal non-sanitized build is supported
with `CN46750_SANITIZE=OFF`.

The `.hex` fixtures are manually specified expected wire bytes from Tables 1-3,
not output generated by the library. The test compares encoding to these fixed
bytes and independently checks decoding of the same fixed fixtures. This checks
more than encode/decode agreement. It does not establish receiver interoperability
or conformity of an unspecified radio envelope.

| Fixture | Inputs and expected layout |
| --- | --- |
| `mandatory.hex` | All 17 mandatory fields. Type `FF`, V1.0 `20`, data length 66, flags `DF E5 FE`, total 72 bytes. |
| `all_fields.hex` | All 21 fields. Data length 72, flags `FF FF FE`, total 78 bytes. |
| `unknown.hex` | Mandatory fields present; registration unfilled; all fields that have an unavailable sentinel use it. Status 4; accuracy values 0. |

Common known values: identifier `12345678901234567890`, registration `ABCDEFGH`,
small aircraft (2), GCS position type (1), GCS longitude +1 degrees / latitude -2
and altitude 100 m, aircraft longitude -3 / latitude +4 and altitude 200 m,
track 123.49 degrees -> 1234, ground speed 12.39 m/s -> 123, airborne status (2),
WGS84 (0), horizontal/vertical/speed accuracy 9/4/3, timestamp
`0x060504030201` ms -> bytes `01 02 03 04 05 06`, timestamp accuracy 5.
The all-field vector additionally uses operation category 2, relative altitude
10 m -> 18020 (`64 46`), descending speed -2.5 m/s -> `85`, pressure altitude
50 m -> 2100 (`34 08`). Timestamps/identifiers are synthetic protocol fixtures.

Additional cases cover unknown-versus-zero, empty registration, numerical
boundaries, NaN/Inf and huge finite values, reserved enum/accuracy codes,
48-bit overflow, short output buffers, every truncated prefix, invalid lengths,
missing fields, unterminated flag chains and extension reporting. Every decimal
0.1-degree and 0.1-m/s representable code is checked against float input to catch
rounding errors at quantization boundaries.
