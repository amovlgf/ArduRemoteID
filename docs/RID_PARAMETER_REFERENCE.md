# AMOV RID 模块参数表

适用固件：AMOV_RID_TEST，AMOV RemoteID 中国模式及签名激活版本。本次设备页面显示版本 1.15（01b43e45）。整理日期：2026-10-21。

设备 UID：`10003BD1F310`。本次在线 RID 节点为 `124`，飞控节点为 `1`。节点编号以 `uavcan status` 的实际结果为准，UID 用于确认设备身份。

表格统一使用“参数名、参数值、参数含义”三列，包含 35 项普通参数表条目及 12 项只读身份状态字段。

- **已确认**：本次设备命令读回或管理页面已显示的值。
- **默认**：当前固件的初始值；设备保存过的配置可能覆盖默认值。
- **授权值／授权预期**：本次 rev1 测试授权包中的内容，不等同于每个字段都已单独读回。
- **运行时读取**：随运行变化，不能当作固定配置保存。

## CAN 通信与模式

| 参数名 | 参数值 | 参数含义 |
| --- | --- | --- |
| `CAN_NODE` | 默认：`0`；运行节点已确认：`124` | RID 自己的 CAN 节点配置。`0` 为自动分配，`1～127` 为固定节点；固定节点不能与同一总线上的其他节点重复。自动分配时，此参数可以保持 `0`，在线节点则显示实际分配的 `124`。修改配置后需重启。 |
| `CN_CAN_NODE` | 已确认：`1`；默认：`0`，表示未配置 | 指定中国模式接受 Location 和 System 消息的来源节点，正常配置范围 `1～127`。这里的 `1` 是飞控节点，不是 RID 自身节点。通过 CAN 写入，保存后即时生效。 |
| `CN_WIFI_ID` | 已确认：`02000001`；默认：空 | 中国模式 Wi-Fi 广播封装标识，格式为 8 位十六进制字符串，保留前导零。表示 3 字节 vendor 标识和 1 字节 type。`02000001` 仅为本次台架约定；它不是热点名称或飞机产品码，也不代表已验证的正式互通标识。通过 CAN 写入后即时生效。 |
| `RID_PROFILE` | 当前有效：`1`，固件固定 | 通用定义为 `0` 原 OpenDroneID、`1` 中国模式。当前 AMOV 固件强制使用中国模式，拒绝通过普通参数修改模式。 |
| `LOCK_LEVEL` | 已确认：`0`；支持：`-1`、`0`、`1` | `0` 允许普通参数写入，适合当前联调；`1` 阻止普通 CAN 参数写入，包括锁级别自身，后续通过 SecureCommand 维护通道修改；`-1` 为开发用 OTA 检查放宽。任何值都不能绕过签名激活或修改受保护身份。此板不支持级别 `2`。 |

RID 的 CAN 速率在当前固件中固定为 **1 Mbps**，没有独立的 RID CAN 速率参数。飞控对应使用 `UAVCAN_BITRATE=1000000`；`UAVCAN_ENABLE=2` 提供动态节点分配；`UAVCAN_NODE_ID=1` 对应上述来源节点。这三个是飞控参数，不属于 RID 参数表。

## 管理 Wi-Fi 与调试串口

| 参数名 | 参数值 | 参数含义 |
| --- | --- | --- |
| `WIFI_SSID` | 默认及本次配置约定：`B950_RID` | 管理热点名称。本固件最多保存 20 字节的名称；已保存的名称优先于编译默认值。 |
| `WIFI_PASSWORD` | 默认及本次配置约定：`987654321` | 管理热点密码，本固件使用 8～20 字节密码。通过 CAN 参数读取会返回 `********`，不是返回明文密码。 |
| `WIFI_CHANNEL` | 默认：`6`；范围：`1～13` | Wi-Fi 信道，作用于当前管理 AP 和中国广播使用的 Wi-Fi 接口。 |
| `WIFI_POWER` | 默认：`20 dBm`；范围：`2～20 dBm` | Wi-Fi 发射功率设置。驱动会进行档位映射，设置值不等同于实测射频输出功率。 |
| `WEBSERVER_EN` | 默认：`1`；取值：`0` 或 `1` | 通用网页管理开关。当前中国模式保留管理 AP 和网页，即使设为 `0` 也不会关闭这两个入口。 |

管理地址为 `http://192.168.4.1/`。Wi-Fi 名称、密码、信道、功率及串口波特率在初始化时使用；修改后重启设备，再确认连接和读回结果。

## 固件维护与恢复默认

以下公钥是 OTA 固件和 SecureCommand 维护使用的公钥，**与 `.act` 激活授权包的信任根独立**。表中默认公钥用于识别初始配置，设备当前保存值应按名称读取。

| 参数名 | 参数值 | 参数含义 |
| --- | --- | --- |
| `PUBLIC_KEY1` | 首次初始化默认：ArduPilot 公钥 1 | 第 1 个 OTA／维护公钥槽。公钥是验签材料，不是签名私钥，也不能用于修改已生效的签名身份。 |
| `PUBLIC_KEY2` | 首次初始化默认：ArduPilot 公钥 2 | 第 2 个 OTA／维护公钥槽，作用与第 1 槽相同。 |
| `PUBLIC_KEY3` | 首次初始化默认：ArduPilot 公钥 3 | 第 3 个 OTA／维护公钥槽，作用与第 1 槽相同。 |
| `PUBLIC_KEY4` | 默认：空 | 第 4 个 OTA／维护公钥槽。 |
| `PUBLIC_KEY5` | 默认：空 | 第 5 个 OTA／维护公钥槽。 |
| `TO_DEFAULTS` | 默认：`0`；写入 `1` 触发恢复 | 清除普通参数配置和待生效授权，然后重启。保留已经生效的签名身份；当前 `CN_CAN_NODE`、`CN_WIFI_ID` 等普通配置会被清除，需要重新设置。它是操作触发项，不是普通状态开关。 |

当前默认公钥字符串如下，设备上的实际内容可使用 `uavcan param get 124 PUBLIC_KEY1` 等命令读取：

```text

PUBLIC_KEY2
PUBLIC_KEYV1:X8jdVqxIIUmCuMSi8IhTZ40VkXW0gbRczzMtdSghqCI=
PUBLIC_KEY3
PUBLIC_KEYV1:snNHkX96F9A+/ISppHZrc1jjPo3jMNN+g2PToKhWSgA=

`LOCK_LEVEL=1` 只说明普通写入已锁定。OTA 和维护验签还取决于有效公钥配置；原维护实现存在没有有效公钥时的放行分支，不能仅凭锁级别判断签名保护完整。

## 只读身份与激活状态

以下 12 个字段需要通过名称单独读取，通常不会出现在 `uavcan param list` 的普通参数枚举中。写入请求不会修改身份。锁定或未激活时也可以读取这些字段。

| 参数名 | 参数值 | 参数含义 |
| --- | --- | --- |
| `RID_UID` | 已确认：`10003BD1F310` | 模块设备 UID，12 位大写十六进制字符串。授权包绑定此设备；不同于飞控节点 `1`、RID 节点 `124` 和产品识别码。 |
| `RID_ID_SCHEMA` | 固定：`1` | 当前身份数据接口的格式版本。 |
| `RID_ACT_STATE` | 页面已确认：`1` | 激活状态：`0` 未激活、`1` 已激活、`2` 激活记录无效。判断是否激活应读取此字段。 |
| `RID_ID_REV` | 页面已确认：`1` | 当前已经生效的授权版本 revision。它不是固件版本；未激活时为 `0`。 |
| `RID_PENDING` | 页面已确认：`0` | 待生效授权的 revision；`0` 表示没有待生效授权。非零值不代表已经应用，需要按激活流程在地面完全断电后重新上电。 |
| `RID_UAS_ID` | 页面已确认：`AMOV0123456789012345` | 有效授权中的产品识别码，未激活时为空。 |
| `RID_REG_ID` | 页面已确认：`REG-12345678` | 有效授权中的完整登记号，最多 64 字节；完整登记号未知时可为空。 |
| `RID_UIN` | 页面已确认：`12345678` | 有效授权中的登记标记，通常为完整登记号最后 8 字节；不能用它补造未知的完整登记号。 |
| `RID_CLASS` | 本次授权值：`2` | 授权中的飞机分类：`0` 微型、`1` 轻型、`2` 小型、`3` 中型、`4` 大型。 |
| `RID_ID_HASH` | 本次授权预期：见下方完整摘要 | 有效身份内容的 BLAKE2b-256 摘要，用于核对身份一致性；为 64 位大写十六进制字符串。未激活时为空；重启本身不会改变同一有效身份的摘要。 |
| `RID_BOOT_ID` | 运行时读取，每次启动重新生成 | 本次启动的非零随机标识，用于识别重启和核对多次读取是否属于同一次运行。不是设备永久 UID。 |
| `RID_ACT_ERR` | 运行时读取；结果码 `0～11` | 最近一次授权处理结果。常见 `0` 为 OK、`1` 为已暂存待冷启动、`2` 为原包已生效。它不是激活状态，即使结果为 `0`，仍需读取 `RID_ACT_STATE` 判断是否激活。 |

```

## 查询方法

在 QGC 的 MAVLink 控制台执行下列只读命令。`124` 是本次实际 RID 节点，后续应先用 `uavcan status` 确认节点，再核对 UID。

```text
uavcan status
uavcan param get 124 RID_UID
uavcan param list 124
uavcan param get 124 CAN_NODE
uavcan param get 124 CN_CAN_NODE
uavcan param get 124 CN_WIFI_ID
uavcan param get 124 RID_ACT_STATE
uavcan param get 124 RID_ID_REV
uavcan param get 124 RID_PENDING
uavcan param get 124 RID_ID_HASH
```

`param show ...` 查询飞控自身参数；`uavcan param get 124 ...` 查询 RID 参数。`uavcan param list 124` 枚举普通参数表，12 个 `RID_*` 身份状态字段需要按名称读取。

网页中的 China RID health、经纬度、UTC、China operation status 是运行状态，不属于可直接写入的配置参数。当前 `CN location stale/unknown` 表示指定来源的位置消息没有满足新鲜度和时间有效性要求，需要检查 GNSS 和飞控数据发送。
